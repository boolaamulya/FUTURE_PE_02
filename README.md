## Project Overview
This project demonstrates how AI tools can be used to generate UGC-style ad content for marketing products. The focus is on creating engaging, conversion-based content using structured prompts.

Product Chosen: Herbal Hair Oil  
Target Audience: Young adults, women, hair care users  


## AI Prompt Used

Create a UGC-style ad script for a herbal hair oil. Include a strong hook, problem, solution, and call-to-action. Keep it natural and engaging.


## AI Generated UGC Ad Script

### Ad Script 1
Hook: "Are you tired of hair fall every day?"

I was struggling with severe hair fall and nothing worked. Then I found this herbal hair oil. Within weeks, my hair became stronger, smoother, and healthier.

If you're facing the same problem, you should definitely try this.

Call to Action: Order now and see the difference!


### Ad Script 2
Hook: "This one oil changed my hair completely!"

I started using this herbal oil 3 times a week. My hair fall reduced and growth improved.

Highly recommended for anyone facing hair issues.

Call to Action: Try it today!
